# Security Policy

This website is public. Treat every file as visible to customers, partners, and contributors.

Do not commit:

- Tokens, passwords, API keys, JWTs, private keys, signing secrets, or service credentials.
- Customer data, production IPs/domains, provider account IDs, database credentials, or private topology.
- Hidden bypasses, private business rules, or client-side-only authorization enforcement.

Use placeholders in examples. Report vulnerabilities privately to the maintainers and do not disclose
exploit details in public issues or Pull Requests.
