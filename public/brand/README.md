# Brand Assets

This folder stores public, non-sensitive brand assets for the standalone MNSCloud website.

Current assets are public-safe web exports aligned with `brand_manual.pdf`:

- `mnscloud-logo.png`: primary light-background logo with CLOUD tag.
- `mnscloud-logo-light.png`: dark-background logo variant with CLOUD tag.
- `mnscloud-wordmark-orange.png`: orange MANAOS wordmark.
- `mnscloud-wordmark-green.png`: green MANAOS wordmark.
- `mnscloud-wordmark-stacked-green.png`: stacked green MANAOS wordmark.
- `mnscloud-watermark.png`: oversized decorative watermark for hero and campaign use.
- `favicon.png`: square favicon export.

Official brand rules currently applied:

- Safety Orange: `#F5832E`, RGB `245, 131, 46`, Pantone `1575 C`.
- Hunter Green: `#1D5B31`, RGB `29, 91, 49`, Pantone `7483 C`.
- Primary typeface: Montserrat for body/subtitles.
- Secondary typeface: Oswald for titles.
- Keep clear space around the logo and do not rotate, distort, recolor, add shadows, add textures,
  alter letter spacing, or change the CLOUD tag position.

Do not commit private customer branding, unreleased partner artwork, or files that contain private
metadata.
