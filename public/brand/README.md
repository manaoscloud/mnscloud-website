# Brand Assets

Place approved ManaosCloud brand files here.

Recommended files:

- `logo.svg` or `logo.png`
- `watermark.png`
- `favicon.ico`
- `og-image.png`
- `brand-manual.pdf`

Do not commit private customer branding, unreleased partner artwork, or files that contain private
metadata. Replace `mnscloud-placeholder-mark.svg` after the official logo/watermark is provided.
