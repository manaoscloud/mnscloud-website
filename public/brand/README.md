# Brand Assets

This folder stores public, non-sensitive brand assets for the standalone MNSCloud website.

Current assets are SVG working versions derived from the approved visual direction shared during
implementation:

- `mnscloud-logo.svg`: primary light-background logo.
- `mnscloud-logo-light.svg`: primary dark-background logo.
- `mnscloud-wordmark.svg`: green MANAOS wordmark.
- `mnscloud-wordmark-orange.svg`: orange MANAOS wordmark.
- `mnscloud-watermark.svg`: oversized decorative watermark for hero and campaign use.

When the formal brand manual or original vector files are available, replace these working SVGs with
the official exported assets while preserving the same filenames where possible.

Do not commit private customer branding, unreleased partner artwork, or files that contain private
metadata.
